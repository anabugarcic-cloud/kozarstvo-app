# 🐐 Kozarstvo Vodič & Kalkulator (Goat Farming & Cheesemaking Web App)

Interaktivna web aplikacija namenjena uzgajivačima koza i proizvođačima sira. Aplikacija objedinjuje praktične kalkulatore, tehnološke vodiče za preradu mleka i zdravstveni kalendar u jedinstven, pregledan interfejs.

---

## 🚀 Ključne Funkcionalnosti

- **🧀 Kalkulator Prinosa Sira:** Dinamički proračun očekivane količine sira na osnovu unete količine mleka i odabrane vrste sira (mladi, polutvrdi, tvrdi).
- **🧮 Kalkulator Dnevnog Obroka:** Proračun potrebnih količina sena i koncentrata u zavisnosti od broja koza i faze laktacije/bremenitosti.
- **📅 Kalendar Jarenja:** Automatizovano izračunavanje očekivanog datuma jarenja na osnovu datuma pripusta (`datetime` logika).
- **🥛 Tehnologija Prerade Mleka:** Vodič kroz pasterizaciju, pravilno brzo hlađenje, tehnologiju sirištenja, okretanje i suvo soljenje sira.
- **💉 Zdravlje i Prevencija:** Preporuke za preventivnu vakcinaciju, dehelmintizaciju (čišćenje od parazita) i obavezne zakonske mere.
- **📋 Registar Rasa:** Pregled najčešćih mlečnih i kombinovanih rasa koza.
